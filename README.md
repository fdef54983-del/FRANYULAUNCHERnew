# FranyuLauncher

FranyuLauncher is an Android launcher for Minecraft: Java Edition. It is designed to let you install, configure, manage, and launch Java Edition instances from an Android device, with a mobile-focused interface and controls.

This is the FranyuLauncher project: a rebrand and active development line based on code from the PojavLauncher and MojoLauncher ecosystems. The project is not affiliated with Mojang, Microsoft, or Minecraft.

## What FranyuLauncher does

The launcher brings the main parts of a Java Edition setup into one Android app:

- Install and manage Minecraft: Java Edition versions and game instances.
- Download game files and assets with progress reporting, retries, resume support, and integrity checks.
- Select and manage Java runtimes used to run the game.
- Choose between the available mobile rendering paths, including GL4ES and Zink where supported by the device.
- Configure touch controls, keyboard mappings, controller mappings, resolution, mouse size, and JVM arguments.
- Use the game directory, logs, mod installers, and other launcher tools from the Android interface.
- Keep the launcher session's version metadata available locally and show offline download status when network access is unavailable.
- Check for FranyuLauncher updates and present release notes inside the launcher.

The exact performance and compatibility depend on the Android device, its GPU, the selected renderer, the Java runtime, and the Minecraft version or modpack being launched.

## FranyuLauncher development

Current development is focused on making the launcher feel like FranyuLauncher rather than an unmodified upstream build. Recent work includes the earth-and-emerald visual identity, FranyuLauncher application branding, a redesigned home screen with recent instances, a collapsible navigation rail, last-played instance information, a release update dialog, and a launcher update provider.

The project still contains inherited Java namespaces and native/JNI integrations from upstream. They are intentionally preserved for now because generated resources and native components depend on them; a complete namespace migration is a separate refactor.

## Download and install

Download a release from the Releases page and install the APK from that release's Assets. When both variants are published:

- The regular APK includes the bundled Java runtime and is the recommended choice for most users.
- The no-runtime APK is smaller but requires a compatible runtime to be available on the device.
- An AAB is intended for store distribution and is not the normal direct-install file.

Do not install the source ZIP generated by GitHub. For the file you download, use the matching SHA-256 checksum when one is published.

## Build from source

The main debug APK can be built with:

    ./gradlew :app_pojavlauncher:assembleFullDebug

The app module currently targets Android SDK 35 and has a minimum Android SDK of 21. Release builds and their signing configuration are defined in the Gradle and GitHub Actions files; do not expect a local release build to have the project's release signing credentials.

## Authentication and privacy

The current build keeps the existing Ely.by login flow compatible while the project's own authentication configuration is developed separately. Review the privacy policy files in this repository before distributing a build.

FranyuLauncher is under active development and may not be stable on every device. It is not affiliated with Minecraft, Mojang, or Microsoft.
